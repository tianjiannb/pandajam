## 死亡装置 = 血肉能量垃圾桶（贴图动画 + 吞噬死亡）

- `scenes/death_trap.tscn`：原红色 Polygon2D 换成 Sprite2D 贴图（保留 uid://bsw5us7qkeami 与碰撞 40x40）。
- `scripts/death_trap.gd` 重写：三态动画——idle 血肉呼吸脉动 + modulate 明暗呼吸、
  devour 张口咬合（弹性 scale）+ 血色粒子爆发、active 激活提亮；桶口上方 CPUParticles2D 能量微粒。
  信号/开门机制完全保留（active 0->1 边沿广播、restore 新一轮清零）。
- 玩家新增 `player.gd:on_devoured(trap)`：被吸向桶口 + 旋转卷入 + 缩小染血消失，**不留尸体**，
  但正常走重置并生成「过去的你」（ghost/开门信号不受影响）。`_devouring` 标志在吞噬期间冻结
  `_physics_process` 的移动/录制/摇晃。DeathTrap 优先调 `on_devoured`，无则回退 `on_bullet_hit`
  （子弹/激光/副本仍走默认死亡）。`_reset_visual()` 增加恢复 scale/modulate/_devouring。
- 素材：`assets/traps/trap_idle.png`（闭合）、`trap_devour.png`（张口血口），ImageGen 生成。
- 生图坑（重要）：ImageGen 的 `background="transparent"` 实际返回**白底**图，需自行去背。
  处理链：边缘 flood fill 去白底 → 只保留最大连通域去噪 → 低 alpha 去雾 → 近白色二次 flood fill 去背景云。
  大 PNG 直接 NEAREST 缩到 66px 会糊，先 LANCZOS 缩到 256 再 `texture_filter=LINEAR`。
  粒子若从核心前方发射会盖住宝石细节，应放桶口上方。
