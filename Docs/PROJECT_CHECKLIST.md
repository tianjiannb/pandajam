# 项目基础功能清单

## 当前项目定位

Godot 4.7.2、Windows、2D俯视角、GL Compatibility。
核心体验：玩家在倒计时内安排行动，循环结束后由“过去的你”重演上一轮动作，玩家利用它们协作通过机关并到达终点。

## 最小版本验收标准

1. 游戏可以正常启动并显示玩家、场景和倒计时。
2. 玩家可以移动、跳跃，并在循环结束后看到“过去的你”重演。
3. 玩家可以使用压力板、门、死亡装置和特殊门完成基本协作。
4. 玩家死亡后不会永久丢失历史“过去的你”。
5. 玩家进入终点后显示完成提示，且按 R 可以重新开始。
6. Godot headless 导入和运行无错误。
