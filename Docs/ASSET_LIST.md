## 9. 全局交付规范

1. **颜色与透明**：sRGB；PNG-32 带 alpha，**不使用预乘 alpha**；透明区域清理干净（无半透明残边）。
2. **尺寸基准**：以 32px 为准的整数倍；角色 32×48、机关 64 级、门 128×12、跳跃障碍 48×96。所有图导出 @1x，另交 @2x（整数倍放大，非插值）。
3. **像素风设置**：项目侧纹理过滤 = Nearest、关闭 mipmap；美术需保证像素对齐（不出现 0.5px 偏移、不做非整数缩放）。
4. **枢轴 / 对齐**：角色脚底中心；机关几何中心；门左端或中心（交付时注明，程序侧统一按中心处理）。
5. **动画**：spritesheet 横排、帧序从左到右、帧率为 12fps 基准（可注 8/12/16 需求）；同时交 **Aseprite JSON 帧表**（含每帧时长与循环标记）。
6. **图集**：单图集不超过 2048×2048；同类资产同图集（角色一集、机关一集、UI 一集）。
7. **命名**：全小写 `snake_case`，前缀分类 + 用途 + 状态/编号，例：
   `char_player_run_4dir.png`、`prop_plate_01_active.png`、`prop_door_01_open.png`、`ui_countdown_digits.ttf`、`sfx_jump_01.wav`、`bgm_main_loop.ogg`。
8. **目录结构**（与现有工程一致）：
   ```
   assets/
     characters/  props/  environment/
     ui/  vfx/
     audio/{sfx,bgm}/
     fonts/
     source/
   ```
9. **交付方式**：单个 zip（含 manifest），版本号 `v主.次`，每次交付附变更说明（新增/修改/废弃）。
10. **验收标准**：Godot 导入无报错、无警告级尺寸异常；帧序播放正确、循环无跳帧；透明通道正确；音频可无缝循环；命名与 manifest 一致。
