## 用途与字号

- `ui_zh_regular.otf`：正文、按钮、说明。16–20px；小于 14px 时中文会糊，不要用。
- `ui_zh_bold.otf`：标题、HUD 标签、按钮重点文字。22–32px。
- `ui_hand_title.ttf`：只用于大标题（成功/失败/暂停页大标题），**≥32px**，小字号笔画会粘连。
- `ui_countdown_digits.ttf`：只含 `0-9 : . - 空格`，用于倒计时数字（36–64px）。这是"或 TTF/OTF"方案；正式倒计时场景优先使用 `assets/ui/ui_countdown_digits.png` 图集 + 手绘 shader。

- Noto Sans SC 的字体仓库根目录未直接提供 LICENSE 文件，本目录使用的是 Google Fonts 中 Noto Sans SC 发行包内附带的 OFL 文本（与 noto-cjk 仓库许可一致）。
- 详细版权行、来源 URL、修改说明见 `licenses/NOTICE.md`。

## Godot 使用

字体已作为 `.otf` / `.ttf` 资源导入，直接：

```gdscript
var font_regular: FontFile = load("res://assets/fonts/ui_zh_regular.otf")
var font_bold: FontFile = load("res://assets/fonts/ui_zh_bold.otf")
var font_title: FontFile = load("res://assets/fonts/ui_hand_title.ttf")
var font_digits: FontFile = load("res://assets/fonts/ui_countdown_digits.ttf")
```

全局默认字体在 `ui/theme/ui_theme.tres` 中配置为 Noto Sans SC Regular。
